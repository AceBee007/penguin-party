# penguin-party

React + PixiJS scaffold for Penguin Party.

## Development

```sh
npm install
npm run dev
```

Local development ports use the `1520x` range by default:

- Vite app: `http://127.0.0.1:15200`
- Signaling server: `http://127.0.0.1:15201`

## Checks

```sh
npm run build
npm run test
npm run test:e2e
```
